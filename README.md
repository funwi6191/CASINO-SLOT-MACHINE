# 🎰 Casino Slot Machine (Java)

A simple **Casino Slot Machine** game built with Java. The player can deposit money, withdraw money, check balance, and spin the slot machine with fruits (🍌 Banana, 🍎 Apple, 🍐 Pear). Designed to demonstrate loops, random number generation, and basic account management.

---

## 🚀 Features
- Deposit money into your balance
- Withdraw money from your balance
- Check current balance
- Spin the slot machine (banana, apple, pear)
- Win or lose based on slot results
- Beginner-friendly Java project
